# Cep Tavlası

İki kişilik ya da bilgisayara karşı, internetsiz tavla.

- **Android:** [APK indir](../../releases/latest/download/CepTavla.apk)
- **iPhone:** Safari'de https://omer-vergisiz.github.io/cep-tavla/ adresini aç, Paylaş → Ana Ekrana Ekle.
- **İki telefon:** Android uygulaması hotspot üzerinden oyunu kurar; Android ya da iPhone katılabilir.

Her `main` güncellemesinde GitHub Actions APK'yı derler ve web sürümünü yayınlar.
